DarkMail – Project Description

DarkMail is a modern, secure, web-based internal email and communication management system designed for organizations to manage employee-to-employee communication efficiently. The application provides a centralized platform where employees can send, receive, organize, and manage messages within the organization.

The system is built using React.js for the frontend and Node.js with Express.js for the backend, with MongoDB used for data storage. Authentication and authorization are handled using JWT (JSON Web Tokens), allowing secure access to protected resources based on user roles.

DarkMail supports separate Admin and User experiences. Administrators can manage employees, monitor the communication system, and perform administrative operations, while users can compose messages, manage their inbox, sent messages, drafts, trash, and other email-related activities.

Key Features
🔐 JWT-based authentication
👤 Employee registration and management
📧 Send and receive internal emails
📥 Inbox management
📤 Sent messages
📝 Draft messages
🗑️ Trash management
